# Harness v0.2.132

Desktop release for macOS, Windows and Linux: archived chats stay out of other
agents' conversations, coordination between agents no longer chimes, and
session sounds follow Focus on macOS. A chat opened through a symlinked folder
resumes after a quit, and the sidebar can search sessions by name.

## Agents and archived chats

- Archiving a chat takes it out of agent-to-agent traffic. A message from
  another chat to an archived one is refused with an "archived" error instead
  of starting a turn, mail queued before the archive is held until you restore
  the chat, and room mentions no longer wake it. Restoring or prompting the
  chat yourself works as before (#498).
- A turn that only answered another agent's message finishes silently: no
  completion sound, "Run finished" banner or phone notification. Work you
  asked for still alerts when it finishes, even when it consulted other agents,
  and an archived chat never sounds a completion (#499).
- A chat opened through a symlinked folder (`/tmp` on macOS, for example)
  resumes its conversation after Harness quits mid-turn, instead of starting a
  new session (#530).

## Sounds and notifications

- On macOS, with desktop notifications on, a session chime while Harness is in
  the background plays as the notification's own sound, so Do Not Disturb,
  Focus and Harness's notification settings apply to it. With Harness in front,
  or with notifications off, chimes play as before (#518).

## Composer and sidebar

- Pasted text that mentions a command, like `/resume`, stays plain text; only
  choosing a completion makes a command (#506).
- Prompt history (↑) no longer recalls messages delivered by other agents or
  rooms (#516).
- The sidebar can search sessions by name (#492).
- Open in Harness and Open in external browser work on links in a split pane
  that isn't focused (#456).

## Cloud

- Creating a cloud sandbox offers the available sizes with their hourly price,
  and running sandboxes show their size and rate.
- Settings has a GitHub CI page for connecting repositories to CodeGraff
  runners, with budgets, concurrency and per-repository defaults.

## iOS

- A queued message can have images added, replaced and removed from its
  Attachments editor, from Camera, Photos or Files (#187, #493).

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
