# Harness v0.2.127

Desktop release for macOS, Windows and Linux: math in replies, chat-tab and
session fixes, and more reliable checkout tracking.

## Replies

- Render math as readable text. Formulas written as `\(w_0\)`, `\[ … \]` or
  `$$…$$` showed as `(w_0)` and `[ h(x)=w_0+w_1x ]`; they now read as `w₀`,
  `h(x)=w₀+w₁x`, `∑ᵢ₌₁ⁿ`, `α ≤ β`, `(a+b)/n`, with display math on a line of
  its own. A single `$` (prices), escaped punctuation like `\[1\]` and code
  stay literal.
- Make URLs in expanded tool output clickable, with the same Open/Copy menu
  and validation as links in replies. The output is otherwise still verbatim.

## Chat tabs and sessions

- Close any chat tab from its row in the sidebar: the tab number turns into ✕
  on hover.
- Empty tabs (a new-session canvas, or a tab whose chats are gone) no longer
  come back as phantom "New session" tabs after a relaunch.
- Opening a chat from a notification or link reveals it in its tab, or gives
  it a new one, instead of replacing the current tab.
- Recall a session's earlier prompts with Up and Down in the composer.
- Reopening a window from the Dock no longer replays the setup splash.
- An older sidebar snapshot no longer overwrites a newer one.
- Restore an archived session reliably when it is prompted again.

## Agents and checkouts

- A chat records its checkout only for runs that were accepted. A run whose
  checkout can't be observed keeps the last known one, marked unavailable,
  and PR lookup and the branch label stop trusting it (#356).
- When a chat's PR was found only from a shared branch, the footer says so
  and shows a merged or closed PR in muted text instead of as this chat's
  status (#357). A chat in its own worktree keeps its PR as before.
- Cap a chain of self-continued turns at 20 resumes or 30 minutes, so an
  agent that never ends its turn can't run on and drain the sync quota.
- Back off on quota rejections instead of retrying every 5 seconds.

## Sign-in

- A sign-in refresh whose answer was lost no longer signs the device out: the
  rejection that follows gets one retry. A second rejection, or an invalid
  credential, still signs out at once.

## Diagnostics

- When the transcript viewport alternates between two positions, the warning
  now logs what differed between the frames and the scroll state behind them
  (#23).

## iOS and Android source changes

- Math in replies renders the same way on iOS and Android.
- iOS split view: Back returns to the session list, and typing an answer to a
  question gives the session the screen so the keyboard doesn't hide the
  field.

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
