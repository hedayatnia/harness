# Harness v0.2.133

Desktop release for macOS, Windows and Linux: long chats no longer drop the
connection to the engine, a run that fails because you're signed out or out of
usage says so with a Log in button, and Settings can delete every archived
session at once. Many smaller fixes come from upstream Zeron.

## Agents and sessions

- A long chat no longer makes Harness lose its engine and report that the
  engine keeps stopping. Large messages are now sent in pieces.
- A run that fails because the agent is signed out or has reached its usage
  limit shows "Signed out" or "Limit reached", with a Log in button that opens
  Accounts on the computer the chat runs on.
- A subagent's opening prompt appears once in its transcript, not twice.
- The effort slider runs from lowest to highest for every agent that
  advertises effort levels.
- A new worktree chat no longer fails without an error when a git hook in the
  repository needs a tool from your shell's PATH.
- Cmd+K's Recent Files no longer flicker while the list loads.
- Pushing to a remote whose push URL is disabled uses its fetch URL.
- Claude Code: dated model IDs fold into their model's row, and a sign-in
  whose Keychain write is refused is saved to the credentials file instead.
- Cursor: runs on a Plus subscription send the model's default options.
- OpenCode 2: the question tool's forms can be answered, and a question no
  longer appears twice.
- Codex: a global npm install that is missing its native binary is repaired
  before the first run.

## Desktop

- Settings → Archived can delete every archived session, after a
  confirmation.
- The sidebar's Show menu can hide the Archived section.
- The mouse's back and forward buttons move through your history.
- An idle subagent tab shows its agent's icon.
- Clicking a file on a tool call opens it in the files panel, and the file
  viewer can open it in your default editor.
- Text in an expanded tool call's output can be selected and copied.
- On macOS, files dropped from any folder, including Downloads, attach, and
  text fields no longer offer one-time-code AutoFill.
- "New project" in project menus drops its ellipsis.

## iOS

- A session can be deleted from the Sessions list, after a confirmation.
- A run that fails because you're signed out or out of usage says so.
- Images can be dragged into a chat or the composer, from Photos, Files or a
  screenshot thumbnail. They stage as attachments and aren't sent until you
  send.
- When switching a project's branch fails, the reason stays visible next to
  the branch picker.
- Home drops the All / Needs you / Running filters and the "need you ·
  running" totals; every session stays listed with its own status. Android
  matches.
