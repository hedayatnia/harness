# Harness v0.2.131

Desktop release for macOS, Windows and Linux: Claude Code sessions that leave
work running in the background are no longer stopped after 30 idle minutes,
and a quit or update now picks interrupted work back up. Pending agent
questions stay visible, inline math renders, and split panes accept dropped
images.

## Agents keep working

- A Claude Code session waiting on its own background work (a background
  command, monitor, agent or workflow) is no longer stopped after 30 minutes
  without a new message. Stopping it killed that work (#517).
- An agent that keeps waking to answer its own finished background tasks is no
  longer treated as a runaway loop. A turn that keeps resuming with nothing
  settling still stops, now visibly with a message saying why (#341, #517).
- Quitting or updating Harness no longer drops work for good. A turn that was
  running is sent again on the same Claude Code or graff session when Harness
  starts, and an agent whose background work the restart stopped is told, so
  it can start that work again (#482).
- A queued prompt no longer sends itself after a turn fails. The queue pauses
  until you send or retry (#466), and a steer accepted just before the failure
  waits in the queue rather than starting a new turn (#467).
- A chat woken by a phone message keeps listening for the command while you
  open other chats, so the message no longer waits until you visit it (#412).
- When a chat's sync push quota runs out, only its own pushes wait; rows and
  other chats keep syncing, and retries back off (#344).

## Questions and the composer

- Pending agent questions open on their own, open again when you reselect the
  active session, and come back after an answer fails to send (#479).
- A half-typed answer survives switching tabs (#478).
- A protected queue edit sent from the phone is confirmed as soon as it is
  saved (#465).

## Tabs, panes and the sidebar

- ⌘⇧T reopens a closed split pane in its place. ⌘W archives and closes a
  session, and ⌘⌥W only closes it (#455).
- An archived session keeps its pane after ⌘D makes it inactive (#489).
- Images can be dropped onto any open pane, which becomes the active one
  (#488).
- Web links open from a split pane that isn't focused (#456).
- Hovering a session in the sidebar shows a ⋯ menu button next to Archive
  (#475).
- After the app is unresponsive for a while, the keyboard shortcuts pressed
  meanwhile open one new tab or split, not one per press (#342).

## Transcript

- Inline `$…$` math renders, while prices like `$5` stay as written.
- On macOS, accents over capital letters show (`X̄`, `X̂`); they used to sink
  into the letter.
- Images an agent opens to look at show under its reply (Claude Code).
- Subagent controls read "Waiting on subagent", "Message subagent", "Resume
  subagent" and "Close subagent", and unnamed workers no longer get empty
  transcript tabs (#468).
- A message sent from another device that is still waiting for this computer
  shows how long it has waited (#413).

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
