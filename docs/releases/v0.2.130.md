# Harness v0.2.130

Desktop release for macOS, Windows and Linux: ⌘⇧T reopens a closed tab where it
was, Markdown images show in agent replies, and graff follow-ups in a worktree
start again. Branch renames the chat's own agent made no longer ask for
confirmation.

## Tabs and transcript

- ⌘⇧T (Window → Reopen Closed Tab) reopens the last closed chat tab at its old
  position, with its split and project. Pressing it again goes further back,
  up to 20 tabs. Sessions archived by closing the tab come back. Off macOS
  the shortcut is Ctrl+Alt+Shift+T, because Ctrl+Shift+T already opens a new
  chat tab. You can rebind it in Settings → Shortcuts (#455).
- Images in agent replies (`![alt](path)`) render as images instead of their
  caption. Relative paths resolve from the chat's folder, and `file://` and
  Windows drive paths work (#400).
- A text selection can start in the whitespace beside a line, so the first
  character is easy to catch.
- Clicking a link works even when its destination preview would cover it or
  other text is selected (#456).

## Agents and graff

- A branch rename made by the chat's own agent (`git branch -m`) no longer
  asks you to confirm the branch change on the next message (#453).
- After "send now" interrupts a turn in a graff worktree, the follow-up no
  longer fails with "that workspace name is already a worktree or branch".
  Harness now launches graff from the main checkout (codegraff#1693).

## Development builds

- A development build of Harness never installs a release update, so it
  keeps its own identity, data folder and port (#452).

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
